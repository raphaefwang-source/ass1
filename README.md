# Method A — Experiment 1 only

This cleaned branch is based on the **latest completed Experiment 1** commit `27789f6cc032509337f3951ed42b1eb6135ee576`. The original experimental branch (`claude/intelligent-bell-62t6pg`) is unchanged and remains available for recovery.

## Retained experiment

- **Fig. 1(a):** uniform, moderately clustered, and strongly clustered particle configurations.
- **Fig. 1(b):** analytical Ewald split identity, `K = K_S + K_L`.
- **Fig. 1(c):** short-range cutoff validation; the floating-point/reference floor is shown with open markers.
- **Fig. 1(d):** relative **matrix-free PPPM action error**, `||Gamma_h X - Gamma_ref X|| / ||Gamma_ref X||`, displayed separately for three configuration families and N=128,256,512.

All latest Experiment 1 CSV data, plots (main and supplementary), paper subsection, report and **21 unchanged position configuration .npz files** are under `benchmarks/method_A_clustered/validation_exp1/`. The numerical data and published figures were copied unchanged from the latest source commit.

## Essential code

- `benchmarks/method_A_clustered/common.py`: Method A physical parameters and reference entry points.
- `cached_operator.py`, `neighbor_images.py`: production matrix-free PPPM action and real-space pair enumeration.
- `direct_periodic.py`, `error_validation.py`, `parameter_optimizer.py`: independent direct reference and Experiment 1 error estimators.
- `clustered_configurations.py`: three spatial distribution generators.
- `validation_exp1/exp1_dense_reference.py`: mode-space dense cross-check, extracted from an old search script.
- `ewald_longitudinal/`: **seven required numerical implementation dependencies** for the Ewald radial kernel, B-spline FFT mesh, literal matrix-free action and full-periodic reference. These modules still contain some unused historical functions; they remain so that no core numerical formula is accidentally changed during the cleanup.

No unrelated experiment directories, historical scaling outputs, Model B datasets, duplicate paper trees or obsolete parameter-search scripts are included in this branch.

## How to reproduce

```sh
python -m pip install numpy scipy matplotlib mpmath
cd benchmarks/method_A_clustered/validation_exp1
python plot_exp1.py                   # reproduce saved figures from CSVs
python run_exp1.py configs refs       # regenerate missing independent dense references
python run_exp1.py action action_p action_fits
# python run_exp1.py all               # complete Experiment 1, expensive
python report_tables_exp1.py > results/tables_exp1.md
```

Raw dense matrices live in a git-ignored `benchmarks/method_A_clustered/raw/` folder, and are regenerated by the `refs` stage. `run_exp1.py` creates the missing cache directory and does not treat saved JSON metadata as a substitute for missing matrices.

**Verification:** A static audit of imports found no missing project modules, and all 21 input configurations and latest figures are present. A clean-environment numerical rerun has **not** been executed as part of this GitHub-only cleanup. Before using this branch as a publication/release source, run `python run_exp1.py all` and compare generated numbers/figures with the committed results.

The optimization source for the pinned N=512 parameters is archived in Git history: `xi=0.85`, `rc=4.88775618844242`, `kc=9.358534792617089`, `p=9`, `M=40`.

## New spatial-accuracy experiments (c = 1 kernel)

Two further experiments live next to the original Experiment 1, whose results above are unchanged:

- `benchmarks/method_A_clustered/validation_exp1/accuracy_sweeps/`: Candidate 1 (θ = 0) accuracy against a converged
  direct periodic reference (R_D chosen per κ, validated against LatticeFriction), with six one-at-a-time sweeps
  (s_R, s_F, M, p, ρ, κ). See `report.md`.
- `benchmarks/method_A_clustered/validation_exp1/candidate2_pilot/`: Candidate 1 vs Candidate 2 (θ = 1/2, isotropic
  Gaussian-corrected split) on identical kernels, positions, references, probes, cutoffs and FFT mesh. See `report.md`.

Shared code is in `validation_exp1/ewald_exp_lib.py`, and dense references are cached in the git-ignored
`raw/exp_refs_c1/`. Each driver has a `smoke` mode and an `all` mode; `validation_exp1/slurm_exp_sweeps.sb` is a
SLURM job with no account or partition set.
