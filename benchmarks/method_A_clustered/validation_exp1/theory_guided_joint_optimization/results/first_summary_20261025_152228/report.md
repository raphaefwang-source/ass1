本次最快 tested-grid configuration 为 **(ξ,sR,sF_req,M,p)=(1.3,2.8,3.3,20,4)**；实际 sF_eff=3.2986354，最大 EΓ=9.26333022e-05，cached complete matvec=1.068917 ms。这是自适应离散搜索中的实测最优，未证明全局最优。

## Reference、核和理论初始化

现有本地副本中未发现 κ=.2 缓存，因此只生成九份必要 reference。每份调用原 direct_periodic.annulus_tensors，以 g(r)=exp(-.2r)/r 直接累加到 R_D=190，并保存八个半径的收敛记录和认证尾界≤1e-13。三进程构建，各进程单线程；所有构建任务结束后才进行最终计时。新旧物理状态的 cache key 不同，加载时核对 κ、c、位置 hash 和来源。历史 κ=.2 的范数仅用于选取求和半径和事后交叉核对，没有替代矩阵数据。

理论公式、条件及 Landau/Fast DPD 文稿适用范围见 stage1_theory.md。Landau 原文控制自由空间系数误差，其结论不能直接转化为周期谱算子证书。本次没有固定三项预算，也没有用保守理论界永久排除候选。

生产 Fourier 系数与加密积分、短程闭式与积分的数值一致性见 coefficient_audit.json。最终候选的 BR/BF/BM、真实 Γ_D 归一化及对角块下界见 final_theory_bounds.csv；quadrature 项是数值估计。

ER 使用 sR_far=8 的直接短程算子；EF 使用 sF_far≈7 的独立 mesh-free Fourier 算子作为无限 cutoff 的数值近似。无限极限的分割重构残差已记录并检查<1e-10。EM 严格比较同一 rc、kc 和同一 reciprocal shells 上的 PPPM 与 mesh-free 算子。Ecutoff 则直接比较该 mesh-free 总算子与独立 Γ_D。

error_decomposition.csv 同时保存矩阵误差相加的 telescope residual、ER+EF+EM 与真实总误差的比值。不同配置的最大值可能出现在不同配置上；谱范数的和不等于总误差，不能通过相减标量误差来推断某个分量。

## 成本模型与瓶颈

以非负最小二乘拟合 TR≈CR Npairs+C0R、Tspread/gather≈CP Np³+C0P、TFFT≈CF M³log(M³)+C0F。FFT 计时包含 influence 乘法和 inverse FFT。模型只解释本实现的实测成本，不能代替目标函数。

| phase | 秒/工作量系数 | 固定秒数 | R² | 相对残差中位数 |
|---|---|---|---|---|
| real | 7.68356e-08 | 3.99557e-05 | 0.2791 | 0.4022 |
| spread_gather | 1.8631e-08 | 6.462379e-06 | 0.3511 | 0.4403 |
| fft | 6.000258e-09 | 0.0005447555 | 0.6103 | 0.4794 |

最快候选：real=0.231792 ms，spread/gather=0.198792 ms，FFT+influence=0.633375 ms，mesh total=0.875375 ms。real/mesh=0.2648，主要被测阶段为 FFT+influence。

旧参数的最大被测阶段为 FFT+influence，优化后为 FFT+influence。最终计时中 real/mesh 最接近1的可行点是 (ξ,sR,sF_req,M,p)=(0.9,2.8,2.8,16,4)，比值 0.9443，完整 1.316292 ms，为最快时间的 1.2314 倍。

组件的独立中位数不要求精确相加。real 与 mesh total 各含对应的缓存 degree 乘法；spread/gather 和 FFT 不含 degree。用于组件计时的表达式逐项复用原 Mesh.apply，并与原 mesh.apply 校验；优化指标始终是未经改写的 op.apply cached action。

## 搜索、验证与计时方法

搜索共记录 4029 个不同请求。顺序为 equal-cutoff coarse slices、独立 sR/sF 平面、局部五参数与 mesh/order 耦合细化、边界/ξ 复查、九组验证和 sensitivity 平面。所有实际参数、shell、合法性及排除原因在 joint_candidates.csv。理论界从未作为永久排除条件。单配置精度超标可直接排除全九组目标；通过单配置者必须另行检查九组，不能将初筛通过误称可行。

单配置初筛可与 reference 生成重叠，初筛时间仅用于临时引导。九份 reference 完成后，按随机顺序重测全部初筛通过者再排名；最终候选始终在同一环境和同一批次共同交错计时。setup 单独独立构建三次，不含 reference、稠密验证或参数核首次初始化。

最终每候选每配置 99 个样本（9轮×11次），候选每次重复随机排序，phase每轮随机排序；每块先warmup3次、每个样本前再warmup1次。单线程环境变量和 threadpool_limits(1) 一致。目标统计量是九个配置各自中位数的中位数。最大相对 IQR=95.02%。

自由候选相对旧参数的配对配置/轮次 block-bootstrap 95% 加速区间为 [1.19554,1.44046]；区间完全大于1，支持本次环境中的加速。 该区间只描述本机本轮，不保证其他机器或系统负载。

最佳候选九组均通过 mesh validity、PSD（最小λ=67.7344356）、symmetry≤5.93e-18、translation nullspace≤1.14e-18、matrix-free/dense≤1.34e-15。

## Discussion

**Q1. 谁主导误差？** 最快点九组 max Ecutoff=4.8628849e-05、max EM=7.4368808e-05，逐配置 EM/Ecutoff 范围 [1.335,1.715]。mesh 不能忽略，误差分量处于可比较的尺度。 ER/EF/EM 的矩阵方向及抵消决定真实 EΓ，不能把范数直接相加当作等式。

**Q2. 之前 M、p 是否过大？** 旧参数 M=20,p=5 在 κ=.2 重测为 1.456042 ms；本次最优 M=20,p=4，完整 1.068917 ms。网格点数为旧参数的 1.0000 倍，assignment 工作量 Np³ 为旧参数的 0.5120 倍；它们是工作量比，不是直接的时间比。固定 cutoff 的 A→B mesh 降时为 52.224%，完整加速 1.68099×。是否过度分辨率应以这些本次数据判断，不能把 κ=.7 的选参认作错误。较小 M/p 的精度失败、合法性限制和每个 p 的最小已测 M 均保留在图2和CSV。

**Q3. 哪个参数最敏感？** 在本次合法且满足精度的 OAT 采样范围内，成本跨度最大的是 M（跨度 5.978333 ms，相对 baseline 354.973%）；从 baseline 出发，sR 可带来最大实测相对降时（33.832%，0.569791 ms）。两种排名回答不同问题，且依赖所测范围。重新优化曲线还允许其余参数变化；两者及成本模型需同时看，不能比较原始数值导数。

**Q4. 最优是否允许 mesh error 接近 cutoff error？** 最优逐配置 EM/Ecutoff 为 1.335–1.715；A/B 对照将误差变化与纯 mesh 速度收益分开。允许 mesh 消耗余量是否有益由上表实测决定，没有人为要求三项误差相等。

**Q5. 放开 sR=sF 更快吗？** 自由/等cutoff 的完整时间分别为 1.068917/1.091000 ms，加速比 1.02066×，配对区间 [0.91697,1.11327]；参数分别为 (ξ,sR,sF_req,M,p)=(1.3,2.8,3.3,20,4) 与 (ξ,sR,sF_req,M,p)=(1.25,2.8,2.8,16,5)。本轮没有分辨出超过波动的自由搜索收益。 这是已测候选中的对比。

**Q6. 主要瓶颈和下一步？** 最快点主要被测阶段是 FFT+influence，应优先优化该阶段的实现/数据移动，再以实际 complete action 复核收益。real/mesh=0.2648，两部分相等不是最优必要条件。

**Q7. 理论尺度覆盖实际区域吗？** sqrt(log(1/ε))≈3.035，而最优 sR=2.8、sF_eff=3.298635。该尺度指导了包含更小 cutoff 的宽初始区域；严格保守界与实际谱误差并不等价。κ=.2 的大零模提高了全算子归一化范数，离散shell、配置几何、aliasing与矩阵抵消还会改变实际最优位置。最终 BR/BF/BM 及 quadrature 估计另表给出，不混作实测误差。

**Q8. 改善超过计时波动吗？** 相对旧参数加速 1.36217×，配对配置/轮次 bootstrap 95% 区间 [1.19554,1.44046]。本轮区间完全大于1，支持实测加速。 单个最小时间不是结论依据；全部重复样本、IQR和环境均已保存。
