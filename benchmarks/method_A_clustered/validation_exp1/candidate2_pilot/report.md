## 1. What was compared

Both candidates use the same:
- kernel, K = c e^{−κr}/r · r̂r̂ᵀ with c = 1;
- configurations;
- dense references Γ_D, from the shared cache `raw/exp_refs_c1`, the same matrices as `accuracy_sweeps`;
- probe vectors;
- cutoffs (s_R, s_F, shell-snapped k_c, ξ = 0.85);
- mesh (M, p, B-spline assignment, influence-function construction) and FFT;
- degree fields and self-cancellation (`CachedGammaH`).

Only the splitting differs:

- K_S^θ = K_S^0 − cθ G(r) I and K_L^θ = K_L^0 + cθ G(r) I, with G(r) = g₃(ξ²) e^{−ξ²r²}.
- K̂_L^θ(k) = K̂_L^0(k) + cθ g₃(ξ²)(π/ξ²)^{3/2} e^{−k²/4ξ²} I. The k = 0 mode is included.

**Implementation** (`ewald_exp_lib.ThetaKernel`, `ThetaOp`):
- Real space: the isotropic term β(r) I, with β = −cθ g₃ e^{−ξ²r²}, is added to the degree tensors and to the per-image contribution of the existing cached D − H action, in the same scatter pass.
- Fourier space: the influence function gets the constant cθ g₃ (π/ξ²)^{3/2} added to A(k)·e^{k²/4ξ²}.
- The positive-mesh algorithm is not changed.
- At θ = 0 the code path is exactly the existing `CachedGammaH`.
- No eigenvalue clipping or PSD repair is applied anywhere.

**g₃** is the Laplace density of e^{−κr}/r³ in s = r², so that e^{−κr}/r³ = ∫₀^∞ g₃(s) e^{−sr²} ds. This is the project's ρ_κ(s).
- Verified numerically to ≤ 2.7e-15 for κ = 0.2, 0.7, 2.
- θ_S(r) e^{ξ²r²} → g₃(ξ²) as r → ∞. θ = ½ therefore balances the leading tail of K_S into eigenvalues ±½ c g₃ e^{−ξ²r²} (longitudinal +, transverse −).
- At practical cutoffs the ratio θ_S e^{ξ²r²}/g₃ is still 1.06 (κ = 0.7, ξr = 4) or 1.16 (κ = 2, ξr = 4) (`results/checks.json`). The asymptotic factor of 2 is therefore not reached exactly.

## 3. Pilot setup

- N = 256, ρ = 0.75, ξ = 0.85, κ ∈ {0.7, 0.2, 2.0}.
- Uniform, moderate and strong configurations. The pilot first ran with seed 1 (`results/pilot_seed1_only.csv`). The ratios were consistent across families, so it was **expanded to seeds 1, 2, 3** (`results/pilot.csv`, 2052 rows).
- **s_R sweep:** 2 … 6.5 (0.25) with s_F = 6.5. **s_F sweep:** 2 … 6.5 with s_R = 6.5.
- M = 80, p = 9.

**Mesh error does not mask the cutoff differences:**
- Every row also carries E_Γ with the exact mesh-free truncated Fourier sum (`E_G_meshfree`) and the mesh-only error.
- The mesh-only error is ≤ 2.2e-14 for both candidates.
- For s ≤ 5, E_Γ and E_Γ_meshfree agree to 0.08 %.
- The reference floor is ≤ 3.3e-15.
- Improvement ratios are reported only where both errors exceed 10× max(reference floor, mesh-only error).

### 4.2 Complete-operator PSD (no repair)

**Short-range pair tensor.** Candidate 2's short-range pair tensor has negative transverse eigenvalues on the retained images, as designed:

| κ | min transverse eigenvalue |
|---|---|
| 0.7 | −0.116 |
| 0.2 | −0.215 |
| 2.0 | −0.0134 |

This is expected and is not a PSD test. The test is on the complete Γ_h.

**Complete Γ_h.** The smallest eigenvalue of sym(Γ_h) on the translation-free subspace Range(Π) is **positive in all 2052 rows** (1026 per candidate), including s = 2. No row has any negative eigenvalue.

| κ | min λ_min, θ = 0 | min λ_min, θ = ½ | λ_min(Γ_ref) |
|---|---|---|---|
| 0.7 | 2.1342 | 2.1419 | 2.1437 (strong s1) |
| 0.2 | 67.721 | 67.734 | ≈ 67.7 |
| 2.0 | 0.01540 | 0.01673 | 0.01685 (strong s1) |

**Direction of the λ_min bias differs between the candidates:**
- **Candidate 1** discards a PSD real-space tail, so its λ_min is biased **downward**. For s ≥ 3 the relative change is between −2.2e-3 and +2.2e-5.
- **Candidate 2**'s discarded tail is indefinite. At small s_R its λ_min is biased **upward**: for s ≥ 3, between −4.9e-6 and +2.4e-3; at κ = 2, s_R = 2 it is +26 % (0.0212 vs 0.0169).
- An upward bias does not threaten PSD. It is, however, a spectral error on the slow modes.

**Slow modes.** At small cutoffs, Candidate 2's **slow-mode action error** (3 slowest eigenvectors) is *larger* than Candidate 1's: ratio 0.23–0.88 at s_R = 2 and 0.64–1.01 at s_R = 3. The two cross over near s_R ≈ 3.5–4, and above that Candidate 2 is better (ratio 1.1–2.6 for s_R ≥ 4).

**Conservation and symmetry.** Momentum residual ≤ 1.8e-17 and symmetry ≤ 1.9e-17 for both candidates.

- Every design meets its target on all 9 configurations (0 failures).
- The ≈ 2× real-space error reduction buys only Δs_R = 0.05–0.10, because E ∝ e^{−s²}: a factor 2 corresponds to Δs ≈ ln 2/(2s). That is a 3–9 % reduction in real-space images.
- The required Fourier shell is the same for both candidates at three of four targets. The ≈ 1.2–1.4× Fourier gain is too small to cross a shell boundary.
- Carrying the isotropic term costs more per image than the images saved. Even with the merged single scatter pass, Candidate 2 is **5–14 % slower** at equal accuracy in all 36 paired comparisons.
- At 1e-10 both candidates use the same mesh (p = 9, M = 36), so the gap is entirely real space.
- A first run of this stage added the isotropic term in a separate scatter pass. It was 13–25 % slower (`results/*_iso_separate_pass.csv`), and is kept for transparency.

## 5. Pilot conclusion

1. **Truncation errors.**
   - Real space: yes, and robustly. E_Γ is 1.64–2.81× smaller, and E_ΓX on Gaussian vectors 1.83–3.55× smaller, at all 378 paired points above the floor (every κ, family and s_R ≥ 2).
   - Fourier space: only marginally. At s_F = 3–5, E_Γ is about 1.2–1.4× smaller (0.95–1.69 over all points), and E_ΓX is 1.0–1.2× smaller (0.84–1.20 over all points; below 1 at s_F = 2 for κ = 2).
   - Exception: on the slowest modes Candidate 2 is *worse* for s_R ≲ 3.5. Its indefinite discarded tail perturbs λ_min upward, by up to 26 % at s_R = 2, κ = 2.
2. **Complete-operator accuracy.** Yes, the gain shows up in the full spectral error ‖Γ_h − Γ_ref‖₂, not only in the kernel-tail prefactor. Its size, about 2×, matches the tail-prefactor argument; it does not exceed it.
3. **Complete-graph PSD.** Maintained. Γ_h restricted to Range(Π) was positive definite in every one of the 1026 Candidate 2 operators, for s_R, s_F = 2 … 6.5 and κ = 0.2, 0.7, 2. This holds even though the short-range pair tensor has negative transverse eigenvalues. No repair was needed or applied.
4. **Equal-accuracy cost.** No credible gain at N = 256 with this PPPM. The factor of 2 in error is worth only 0.05–0.1 in s_R. The additional isotropic per-image work outweighs the 3–9 % saved images, and Candidate 2 was 5–14 % slower at every tolerance from 1e-4 to 1e-10.
5. **Recommendation.** Not promising enough to extend Candidate 2 to the six full sweeps. It remains a valid splitting: exact identity, PSD complete operator, at least as accurate for the same cutoffs except on slow modes at s_R ≲ 3.5. A cost advantage would require a regime where the real-space part dominates much more strongly and per-image cost is unchanged. Examples are larger N at fixed M, or an implementation that fuses the isotropic term into precomputed per-image tensors. These were not tested here.
