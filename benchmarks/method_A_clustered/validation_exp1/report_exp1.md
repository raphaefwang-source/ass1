# Experiment 1 (Model A): spatial accuracy validation of the periodic Ewald–PPPM friction operator

This round only adds a numerical-accuracy validation. Nothing below changes the physical kernel, the Ewald split, the
PPPM production code, or any earlier data:

- The scaling, `psearch` and `direct512` results are untouched.
- No new scaling, Lanczos-rank or BAOAB runs were made.

Every number quoted here is read from `results/` (tables: `results/tables_exp1.md`, generated by
`report_tables_exp1.py`). Figure 1 is `figures/fig1_spatial_validation.{pdf,png}`; supplementary figures are
`figures/figS1–S3`.

## 1. Model and operator (fixed)

- **Kernel A:** K(r) = g(r) r̂r̂ᵀ, with g(r) = c e^{−κr}/r.
  - Constants: κ = 0.7 and c = γ r_ref e^{κ r_ref} = 1.6148 (γ = 0.5, r_ref = 1.3), density ρ = 0.75.
- **Operator:** (ΓX)_i = Σ_{j≠i} Σ_n K(q_i − q_j + nL)(X_i − X_j).
  - Full periodic lattice sum; the Fourier k = 0 term is retained.
  - No minimum image, no free-space or regularised kernel.
- **Ewald split at s = ξ²** (`radial_kernels.RadialEwald`, law A):
  - K_S = c r rᵀ ∫_{ξ²}^∞ ρ_κ(s) e^{−sr²} ds
  - K_L = c r rᵀ ∫_0^{ξ²} ρ_κ(s) e^{−sr²} ds
  - ρ_κ(s) = 2√s/√π e^{−κ²/4s} − κ erfc(κ/2√s).
- **Production action** (unchanged): Γ_h X = Γ_S^{rc} X + D_L^h X − H_L^h(X).
  - Pair-difference form: `GammaH.matvec`.
  - Cached form: `cached_operator.CachedGammaH`.
- **Production parameters** (the measured N = 512 optimum of the Issue #2 round): ξ = 0.85, r_c = 4.8878 (s = ξ r_c =
  4.155), k_c ≤ 9.3585, B-spline order p = 9.
  - k_c is snapped to the largest reciprocal shell ≤ 9.3585 in each box: 9.3408 at N = 128 and 9.3433 at N = 256.
- **"Strict" cutoffs** (convergence experiments only, so mesh errors are visible below the production floor): r_c = 6/ξ
  and k_c ≤ 2ξ·6.

## 2. References and their accuracy

| reference | construction | role |
|---|---|---|
| Γ_ref | `prl_toy_models.LatticeFriction`, `rel_tol = 1e-13`: near images summed directly, far images by a tensor Chebyshev fit, k = 0 included (`raw/<config>_Gref.npy`) | reference for (b), (c), (d) |
| Γ_D55 | unsplit direct periodic image sum to R = 55 (`direct_periodic.DirectPairs`); certified tail bound 5.3–6.4e-14 relative | checks Γ_ref; second reference for (b) |
| θ, θ_S, θ_L at 50 digits | `mpmath` tanh–sinh quadrature of the two s-integrals, analytic θ | reference for the scalar components in (a) |
| Γ_L^ex | mesh-free Fourier lattice sum (1/V) Σ_{\|k\|≤k_ex} e^{ik·(q_i−q_j)} K̂_L(k), k_ex = 2ξ·6.6 = 11.23; certified tail 1.5–1.7e-17 relative (`FourierShells.eps_F`) | exact long-range part for (b) |
| D^{k_c}_L | the same Fourier sum at the production/strict k_c, self terms removed | target of the mesh-transfer error in (c) |

**Measured reference accuracy** (Table "References" in `results/tables_exp1.md`, all 19 configurations):

- ‖Γ_D55 − Γ_ref‖₂/‖Γ_ref‖₂ = 2.1e-15 to 4.2e-15. The two references come from independent constructions.
- Translation residual ‖Γ_ref T‖/λ_max = 4.0e-16 to 8.4e-16.
- Symmetry defect = 0.

So Γ_ref is accurate to a few 1e-15 relative in the spectral norm. Tested errors below about 1e-14 are therefore at the
reference/round-off level, and they are flagged as such wherever they occur.

## 4. Panel (a): analytical split identity K = K_S + K_L

**Design.**
- The three scalars are computed independently: θ = c e^{−κr}/r analytically, θ_S by its erfcx closed form, and θ_L by
  its own graded Gauss–Legendre s-quadrature (`theta_L`, 1940 nodes).
- K_L is never defined as K − K_S.
- Tensors θ r̂r̂ᵀ are formed for every pair image with |d| ≤ 8 of the nine N = 256 configurations (204–207 thousand
  images each, r ≥ d_min = 0.9), for ξ ∈ {0.5, 0.6, 0.75, 0.85, 1.0, 1.2, 1.5}.
- A synthetic radial sweep, r = 1e-6 … 12 (601 points, random directions), covers the small-r region that the
  configurations do not reach.
- At 25 radii (1e-4 … 12) per ξ, each scalar is compared with a 50-digit mpmath value.

**Results** (Table "(a)"; Fig. 1(a); Fig. S1):

- Relative Frobenius error of K − K_S − K_L over all images: **2.0e-16 to 3.0e-16** for every family and ξ.
- Largest single-pair relative error: **1.9e-15**. Largest absolute entry error: **8.9e-16** (max |K| = 0.94).
- Radial sweep, r ≥ 1e-6: largest pointwise relative error **1.5e-15**, and 8.8e-16 for r < 0.9. No growth toward
  small r.
- Against 50-digit mpmath:
  - θ_L is accurate to ≤ 6.7e-16 relative to itself, at every radius.
  - θ_S is accurate to ≤ 8.3e-15 relative to itself for ξr ≤ 7.
  - All three components are accurate to ≤ 1.0e-15 relative to θ.
- The identity error is therefore at float64 round-off, uniformly in ξ and over the three families. It is a few times
  the unit round-off u = 1.1e-16, not 1e-15 or better everywhere: the per-pair maximum is 1.9e-15.

**Small-r cancellation check:**
- Forming K_L as K − K_S loses accuracy as r → 0, because θ_S → θ ~ 1/r while θ_L → O(r²). Measured against mpmath,
  the subtraction gives relative errors in θ_L of **up to 9.3e-3** at r = 1e-4 (Fig. S1, right panel).
- The independent s-quadrature stays at ≤ 6.7e-16.
- This confirms that the identity test must not use K − K_S, and that the production code is right not to evaluate the
  real-space K_L by subtraction (the PPPM uses K̂_L directly).

**Two numerical observations (not defects of the method):**
1. A first run used 30-digit mpmath with coarse breakpoints. It reported a θ_S "error" of 6e-8 at r = 12, which was an
   error of the mpmath reference itself: 60-digit quadrature with breakpoints on the e^{−sr²} scale agrees with the
   closed form to 3e-15. The final run uses 50 digits and the finer breakpoints.
2. For ξr ≳ 11 (θ_S/θ < 1e-50), the closed-form θ_S agrees with mpmath only to about 2e-10 relative to itself. This is
   irrelevant at every cutoff used anywhere (ξ r_c ≤ 7). The value is in `a_split_summary.json`
   (`mp_max_err_theta_S_self`).

## 5. Panel (b): short-range truncation

**Design.**
- ξ = 0.85 and s = ξ r_c = 2.0, 2.1, …, 6.6 (47 values), on the nine N = 256 configurations:
  E_S(r_c) = ‖Γ_S^{rc} + Γ_L^ex − Γ_ref‖₂/‖Γ_ref‖₂.
  - Γ_S^{rc} is the Laplacian of the K_S images with r ≤ r_c (closed-form θ_S).
  - Γ_L^ex is the mesh-free Fourier lattice sum. There is no FFT mesh, and Γ_L^ex is not obtained from Γ_ref or Γ_S.
- The spectral norm is computed by a dense `eigvalsh` of the symmetric part; the antisymmetric part, ≤ 1.1e-16, is
  reported.
- **Also recorded:**
  - E_S against Γ_D55.
  - The exact-arithmetic tail ‖Γ_S^{full} − Γ_S^{rc}‖₂/‖Γ_ref‖₂, where Γ_S^{full} contains every image to 7/ξ plus an
    analytic tail below e^{−49}.
  - The certified bound ε_S = 2 max_i λ_max(Σ_{r>r_c} K_S) + tail (`RealSpaceTail.eps_S`).
- **Fit:** log E = a − c s² by least squares on all points with E > 100 × floor. The floor is the median of the last
  5 points. c is not forced to 1.

**Results** (Table "(b)"; Fig. 1(b)):

- E_S falls from 1.3–1.4e-2 at s = 2 to the floor at s ≈ 5.8.
- Production s = 4.155 lies between E_S(4.1) = 4.7–5.6e-8 and E_S(4.2) = 2.1–2.4e-8.
- **Fitted c:**
  - On s ∈ [2.0, 5.3] (34 points), individual configurations give **c = 0.981–0.987**.
  - Median curves per family give 0.981 (uniform), 0.987 (strong) and 0.983 (moderate).
  - Restricting to s ≥ 3 gives 0.983–0.988.
  - The Gaussian rate e^{−s²} is thus observed with c ≈ 0.98. The small deficit comes from the algebraic prefactor of
    the tail and the growth of the image count with r_c. This is an observation, not a claim of a universal exponent.
- **Floor:** 3.5–4.1e-15 against Γ_ref and 1.8–2.4e-15 against Γ_D55.
  - At s ≥ 6, Γ_S^{rc} + Γ_L^ex reproduces the full periodic operator to this level.
  - This is an operator-level confirmation of the split identity, with Γ_L computed in Fourier space and Γ_S in real
    space.
  - It also shows that the floor is set by Γ_ref/round-off, not by the split.
- E_S agrees with the exact-arithmetic tail to ≤ 1.3e-3 relative wherever the tail exceeds 1e-12. Hence Γ_L^ex and
  Γ_ref are consistent and the curve is pure truncation.
- **Certified bound:** ε_S/(‖Γ_ref‖₂ E_S) = **1.40–1.88** over the fit range (bound ≥ observed in every case).
- **Same-neighbour steps:** none. At N = 256 each 0.1 step in s adds 818–8570 images, so no plateau caused by an
  unchanged neighbour set occurs. All 47 × 9 points are kept.

## 6. Panel (c): degree convergence

**Design.**
- D_i = Σ_{j≠i} K^per_ij, which is the diagonal 3×3 block of Γ. The error measure is
  E_D = (Σ_i ‖D_i^h − D_i^ref‖_F² / Σ_i ‖D_i^ref‖_F²)^{1/2}.
- **Discrete degree:** D_i^h = D_i^S + D_i^{mesh} − W_ii.
  - D^{mesh} is the production FFT degree (`Mesh.degree`, the response to the three translation fields), which
    contains the mesh self response W_ii.
  - W_ii = V^{-1} Σ_k |S_i(k)|² G_h(k) is computed in mode space and removed.
  - Leaving it in would give an error of 7.5e-5 to 1.6e-3 (column `E_D_self_not_removed`). The production action is
    unaffected, because W_ii cancels in D_i X_i − H_i(X).
- **Cross-check:** D^h is compared with the diagonal blocks of the complete dense Γ_h from the mode-space pair matrix
  (`dense_fast`, self terms excluded by `lap_full`). They agree to **≤ 5.7e-16** (30 checks).
- **Two errors are reported:**
  - E_D^complete against Γ_ref.
  - E_D^mesh = ‖D_L^h − D_L^{k_c}‖/‖D^ref‖ against the exact truncated-Fourier degree. This isolates the mesh transfer.
  - The fixed-cutoff floor ‖D^S + D^{k_c}_L − D^ref‖/‖D^ref‖ separates the two.
- **Cases:**
  - `strong` s1 at N = 128, 256, 512 with p = 4, 6, 8, 9.
  - `uniform`/`moderate` s1 at N = 256 with p = 9.
  - Both cutoff settings; only M varies.
- **M grids:** 18–64 (N = 128), 22–80 (N = 256), 28–96 (N = 512), at equal grid spacings h across N.
- **Validity checks at every point:** Nyquist m_c < M/2, η = k_c h/π < 1, and influence-function stability (modes
  with |Ŵ|² < 1e-10 are excluded).

**Validity:**
- 14 of 272 points are invalid, all by Nyquist: with the strict k_c, M = 18 (N = 128), 22 (N = 256) and 28 (N = 512)
  give m_c = M/2. They are kept in `c_degree.csv` with the reason, and greyed in Fig. S2.
- No mode was excluded at any valid point: min |Ŵ|² = 8.4e-4 and max η = 0.945.

**Results** (Table "(c)"; Fig. 1(c) for strong N = 512, production; Fig. S2 for all cases):

- **Mesh-transfer error:** converges algebraically. Least-squares rates on the points ≥ 1e-13 are
  **4.10–4.18 (p = 4), 6.33–6.48 (p = 6), 8.65–8.86 (p = 8) and 10.16–10.43 (p = 9)**.
  - The rates agree across N = 128/256/512, across families, and between the two cutoff settings.
  - Local two-point rates oscillate (e.g. 2.9–5.4 for p = 4) because the error has a grid-phase component; the
    least-squares rates are the quantities to quote. Observed rates are about p for even p and about p + 1.3 for
    p = 9. These are measured, not proven, orders.
- **Production cutoffs:** the complete error plateaus at the **fixed-cutoff floor 2.0e-8 (N = 512), 2.3e-8 (N = 256),
  2.65e-8 (N = 128)**, while the mesh-transfer error keeps decreasing to 5e-15.
  - The plateau is therefore the r_c/k_c truncation, not a failure of mesh convergence.
  - With p = 9 every Nyquist-valid M is already on the floor.
  - p = 8 reaches it at M = 18/24/32 (N = 128/256/512) and p = 6 at M = 28/36/48.
  - p = 4 does not reach it within the tested M range: E_D = 4.2–4.8e-8 at the largest M.
- **Strict cutoffs:** the floor drops to 2.2–4.6e-15 and the complete error follows the mesh-transfer error down to
  5–8e-15 for p = 9.

## 7. Panel (d): matrix-free action

**Design.**
- For N = 128 and 256, 3 families × 3 seeds, both cutoff settings, p = 9 and every M of the grids above, the production
  action Γ_h X (pair-difference `GammaH.matvec`) is compared with Γ_ref X.
- **Probes** are fixed per configuration and the same for every M:
  - five Gaussian X ~ N(0, I_{3N});
  - spectral: the eigenvectors of Γ_ref on Range Π for its smallest and largest eigenvalues;
  - four slow modes cos(2π x_a/L) e_b, (a, b) ∈ {(x, x), (y, y), (x, y), (z, x)}, with the mean removed;
  - three translations e_a ⊗ 1.
- **Error measures:**
  - Non-null probes: E(X) = ‖Γ_h X − Γ_ref X‖₂/‖Γ_ref X‖₂.
  - Translation probes: absolute and operator-normalised residuals ‖Γ_h T‖/(‖Γ_ref‖₂ ‖T‖). Their reference action is
    zero, so they are never divided by it.
- **Dense checks:**
  - E_op = ‖Γ_h − Γ_ref‖₂/‖Γ_ref‖₂ from the dense Γ_h (`GammaH.dense`).
  - Symmetry ‖Γ_h − Γ_hᵀ‖_F/‖Γ_h‖_F.
  - ‖Γ_h T‖.
  - Cached (D − H) vs pair-difference action.
  - λ_min of Γ_h on Range Π and the count of negative eigenvalues there.

**Validity:** 18 of 360 points are Nyquist-invalid (strict cutoffs, M = 18/22) and are kept with the reason.

**Results** (Table "(d)"; Fig. 1(d); Fig. S3). Maxima are over the 9 configurations.

| | N = 128 | N = 256 |
|---|---|---|
| production cutoffs, all M: dense E_op | 3.33–3.44e-8 | 3.49–3.53e-8 |
| production: Gaussian / spectral min / spectral max / slow | 2.8e-8 / 6.7e-8 / 2.0e-8 / 5.1e-8 | 2.7e-8 / 8.0e-8 / 2.0e-8 / 5.3e-8 |
| strict cutoffs: E_op, smallest valid M → largest M | 2.3e-9 (M = 20) → 2.1e-14 (M = 64) | 3.9e-9 (M = 24) → 2.1e-14 (M = 80) |
| strict: Gaussian, smallest → largest M | 9.9e-10 → 1.0e-14 | 1.6e-9 → 1.0e-14 |

- **Production cutoffs:**
  - The action error is independent of M. It is the fixed-cutoff floor, the same truncation floor as in (b) and (c), and
    is about 6× below the production budget 2e-7.
  - The smallest-eigenvalue probe has the largest relative error, 8.0e-8. Its reference action is the smallest
    (λ_min ≈ 3.5 vs ‖Γ‖ ≈ 15.9).
- **Strict cutoffs:**
  - E_op and every probe error decrease with least-squares rates **10.10–10.25** (E_op and Gaussian, points ≥ 1e-13;
    `results/d_action_rate_fits.csv`), consistent with the p = 9 degree rate.
  - The last points, at 1–2e-14, sit at the reference/round-off level.
- **Translation null space:**
  - Pair-difference action: exactly 0.
  - Cached D − H action: ≤ 9.2e-18 (operator-normalised).
  - Dense ‖Γ_h T‖/(‖Γ_ref‖√3) ≤ 4.3e-16, versus 3.1–4.0e-16 for Γ_ref itself.
- **Symmetry:** ≤ 2.1e-17. **Cached vs pair-difference:** ≤ 1.1e-15 relative over all non-null probes.
- **Spectrum on Range Π:** no negative eigenvalue in any of the 342 valid cases; min λ_min(Γ_h) = 3.4589.
  - The relative deviation of λ_min from Γ_ref is ≤ 7.8e-8 (production) and down to 1e-14 (strict).
  - |Δλ_min| ≤ 0.68 ‖Γ_h − Γ_ref‖₂ in every case, consistent with Weyl's inequality.

## 8. What the data support, and what is interpretation

**Supported directly by the measurements:**
- K = K_S + K_L holds to ≤ 3.0e-16 (Frobenius) and ≤ 1.9e-15 (per pair) for ξ ∈ [0.5, 1.5], on all three families and
  down to r = 1e-6.
- At the operator level, Γ_S + Γ_L^ex = Γ_ref to ≤ 4.1e-15.
- The short-range truncation error decays as e^{−c s²} with c = 0.981–0.988, and the certified bound is 1.4–1.9× the
  observed error.
- The mesh-transfer degree error converges at rates of about p (about p + 1.3 for p = 9), independently of N and
  family.
- At the production cutoffs, the complete degree and action errors are flat in M at the r_c/k_c floor:
  E_D 2.0–2.7e-8 and E_op ≤ 3.5e-8, below the 2e-7 budget.
- Under strict cutoffs the full production action converges to 1e-14.
- Structural properties (symmetry, translation null space, positivity on Range Π) hold to round-off.

**Interpretation, not proven here:**
- That c < 1 is caused by the algebraic prefactor of the tail.
- That the odd-p rate p + 1.3 reflects a cancellation in the centred B-spline assignment.
- That the same behaviour holds for N > 512. Panel (c) includes N = 512; panel (d) is dense and therefore stops at
  N = 256. The Issue #2 round gave E_op = 3.03e-8 at N = 512.

## 9. Issues found

- **No mathematical or numerical defect in the method was found.**
- Items that need care:
  1. The mesh self response W_ii must be removed whenever the FFT degree is compared with D_i. Otherwise an apparent
     error of up to 1.6e-3 appears. The production action is unaffected.
  2. K_L must not be evaluated as K − K_S in real space at small r: there is up to 9e-3 relative error at r = 1e-4.
  3. A 30-digit mpmath reference is not accurate enough for θ_S at ξr ≳ 6; use ≥ 50 digits with breakpoints on the
     e^{−sr²} scale.
- **Limitation:** the `strong` family's realised cluster width is about 2.2× the requested one, a consequence of the
  d_min = 0.9 push in the existing generator. "Strongly clustered" here means two dense blobs at liquid-like d_min, not
  point-like clusters.
