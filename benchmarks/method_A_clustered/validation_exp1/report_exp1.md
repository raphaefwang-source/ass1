# Experiment 1 (Model A): accuracy validation of the periodic Ewald–PPPM friction operator

Experiment 1 has one set of results and makes three claims:

1. The Ewald splitting identity K = K_S + K_L holds in double precision (Fig. 1(b)).
2. The short-range truncation error decays as a Gaussian in s = ξ r_c down to the reference/round-off floor
   (Fig. 1(c)).
3. The matrix-free PPPM action Γ_h X is accurate for every tested class of input vectors. With ξ, r_c, k_c and p fixed,
   it converges to the independent periodic reference under FFT mesh refinement (Fig. 1(d)).

Fig. 1(a) shows the particle configurations.

Every number below is read from `results/`. Tables are in `results/tables_exp1.md`, generated by
`report_tables_exp1.py`. Figures:
- Figure 1: `figures/fig1_spatial_validation.{pdf,png}`.
- Supplementary: `figures/figS1_split_radial`, `figS2_action_detail`, `figS3_translation_residual`, `figS4_action_p`.

## 1. Model, operator and references (fixed)

**Model:**
- Kernel A: K(r) = g(r) r̂r̂ᵀ with g(r) = c e^{−κr}/r, κ = 0.7, c = γ r_ref e^{κ r_ref} = 1.6148 (γ = 0.5,
  r_ref = 1.3), density ρ = 0.75.
- Operator: (ΓX)_i = Σ_{j≠i} Σ_n K(q_i − q_j + nL)(X_i − X_j).
  - Full periodic lattice sum, Fourier k = 0 term retained.
  - No minimum image, no free-space or regularised kernel.
- Ewald split at s = ξ²:
  - K_S = c r rᵀ ∫_{ξ²}^∞ ρ_κ(s) e^{−sr²} ds
  - K_L = c r rᵀ ∫_0^{ξ²} ρ_κ(s) e^{−sr²} ds
- **Production action** Γ_h X = Γ_S^{r_c} X + D_L^h X − H_L^h(X):
  - the pair-difference `GammaH.matvec`, the measured-fastest implementation at N = 512;
  - a second path, the cached D − H form `CachedGammaH.apply`.
- Neither the kernel, the split, the PPPM implementation nor the Lanczos code was changed.

**References:**

| reference | construction | use |
|---|---|---|
| Γ_ref | `prl_toy_models.LatticeFriction`, `rel_tol = 1e-13`: near images direct, far images by a tensor Chebyshev fit, k = 0 included | (c), (d) |
| Γ_D55 | unsplit direct periodic image sum to R = 55 (`direct_periodic.DirectPairs`); certified tail bound 5.3–6.4e-14 relative | accuracy of Γ_ref |
| Γ_ref′ (N = 512) | `LatticeFriction`, `rel_tol = 1e-15`, Chebyshev degree 20, `near_cells = 3` | convergence of Γ_ref |
| θ, θ_S, θ_L at 50 digits | mpmath quadrature of the two s-integrals | (b) |
| Γ_L^ex | mesh-free Fourier lattice sum to k = 2ξ·6.6 = 11.23; certified tail ≤ 1.7e-17 relative | (c) |

**Measured reference accuracy:**
- ‖Γ_D55 − Γ_ref‖₂/‖Γ_ref‖₂ = **2.0–4.2e-15** over all 21 configurations.
- `strong_N512_s1`: ‖Γ_ref′ − Γ_ref‖₂/‖Γ_ref‖₂ = **2.7e-15**.
- At the action level, every non-null probe gives ‖(Γ_D55 − Γ_ref)X‖/‖Γ_ref X‖ ≤ **1.0e-14**.
- Errors near 1e-14 are therefore at the reference/round-off level.

## 2. Configurations (Fig. 1(a))

- **Families** (`clustered_configurations.generate`, periodic d_min = 0.9, ρ = 0.75):
  - `uniform`;
  - `moderate`: 3 clusters, σ/L = 0.2;
  - `strong`: 2 clusters, σ/L = 0.08 requested; the d_min push widens the realised σ to about 2.2× that value.
- **Sizes:**
  - N = 128 and 256: seeds 1, 2, 3 per family.
  - N = 512: seed 1 per family. `strong_N512_s1` is the configuration of the joint parameter optimisation.
- 21 configurations in total, all independent draws. d_min = 0.9001–0.9025.
- Fig. 1(a) shows the three families at N = 256 and the N = 512 strongly clustered configuration as 3D scatter plots in
  the unit box.
- No Gaussian spatial cloud or other new position distribution was added.

## 3. Panel (b): analytical Ewald splitting

**Design** (`run_exp1.py split`, results `split_*`):
- θ, θ_S and θ_L are evaluated independently: analytically, by the erfcx closed form, and by θ_L's own Gauss–Legendre
  s-quadrature. K_L is never formed as K − K_S.
- Tensors are formed for every pair image with |d| ≤ 8 of the nine N = 256 configurations (204–207 thousand each), for
  ξ ∈ {0.5, 0.6, 0.75, 0.85, 1.0, 1.2, 1.5}.
- A radial sweep r = 1e-6 … 12 covers small r.
- 25 radii per ξ are compared with 50-digit mpmath values.

**Results:**
- Relative Frobenius error: **2.0–3.0e-16**. Largest single pair: **1.9e-15**. Largest absolute entry: 8.9e-16
  (max |K| = 0.94).
- Radial sweep: ≤ 1.5e-15.
- All components agree with mpmath to ≤ 1.0e-15 relative to θ.
- Forming K_L as K − K_S would lose up to 9.3e-3 of θ_L at r = 1e-4 (Fig. S1). The independent quadrature stays at
  ≤ 6.7e-16.
- **Conclusion 1:** the identity holds at float64 round-off (a few u) for every ξ and family.

## 4. Panel (c): short-range cutoff error

**Design** (`run_exp1.py shortrange`, results `shortrange*`):
- ξ = 0.85, s = ξ r_c = 2.0, 2.1, …, 6.6, on the nine N = 256 configurations:
  E_S = ‖Γ_S^{r_c} + Γ_L^ex − Γ_ref‖₂/‖Γ_ref‖₂, with a mesh-free Γ_L^ex.

**Results:**
- E_S falls from 1.3–1.4e-2 (s = 2) to the floor at s ≈ 5.8.
- log E_S = a − c s² on s ∈ [2.0, 5.3] gives **c = 0.981–0.987** (s ≥ 3 alone: 0.983–0.988). c is not forced to 1.
- The certified bound ε_S is 1.40–1.88 × the measured error.
- At the production s = 4.155: E_S(4.1) = 4.7–5.6e-8 and E_S(4.2) = 2.1–2.4e-8.

**Floor presentation:**
- For s ≥ 5.8, E_S stays at 3.5–4.1e-15 (1.8–2.4e-15 against Γ_D55), while the exact truncation tail keeps falling
  (5.6e-17 at s = 6.6). The flat part is therefore the reference/round-off floor.
- Resolved points (exact tail ≥ 2 × floor, i.e. s ≤ 5.7 in all nine configurations) are drawn as median curves with
  min–max shading. The 9 floor points per configuration are drawn as open markers, with a grey band labelled
  "reference / roundoff floor".
- The e^{−s²} guide covers only the resolved interval. The certified bound is labelled "theory".
- No value was removed or changed.

## 5. Panel (d): matrix-free PPPM action convergence

### 5.1 Design (`run_exp1.py action`, results `action_*`)

**What is plotted:** only the complete error, against the independent reference:

  E(X; M) = ‖(Γ_h(M) − Γ_ref)X‖₂ / ‖Γ_ref X‖₂

- Γ_h(M) X is the production pair-difference action.
- Per configuration, ξ, r_c, k_c and p = 9 are fixed; only the FFT size M changes.
- **M grids:** N = 128: 16–64; N = 256: 20–80; N = 512: 26–96.
- **Validity checks at every M:**
  - Nyquist m_c < M/2 and η < 1;
  - retained mode count = an independent integer count of |m|² ≤ n_c, so every shell is complete;
  - no mode below the influence-function threshold |Ŵ|² ≤ 1e-10.
- **Invalid points:** 63 of 462 cases fail Nyquist and are kept in `action_mesh.csv` with the reason:
  - production: M = 16, 20, 26 for N = 128, 256, 512;
  - strict: M = 16/18, 20/22, 26/28.
- Valid points: no excluded modes; min |Ŵ|² = 7.1e-4.

**Two cutoff settings:**
- **Production:** the measured N = 512 optimum in full double precision (`results_psearch/optimum_strong_N512_s1_main.json`):
  - ξ = 0.85, r_c = 4.88775618844242, k_c = 9.358534792617089 = 2π√172/L₅₁₂, p = 9; production M = 40.
  - At N = 128 and 256, k_c snaps to the largest shell ≤ k_c of that box (n = 68 and 108). These cutoffs were not
    re-optimised for those N.
- **Strict** (convergence demonstration only): ξ = 0.85, r_c = 6/ξ, k_c ≤ 12ξ.
  - Shells n = 81, 128 and 204 for N = 128, 256 and 512.
  - The truncation part ‖Γ_S^{r_c} + Γ_L^{k_c} − Γ_ref‖₂/‖Γ_ref‖₂ is ≤ 5.1e-15, so the complete error measures the mesh.

**Probes:** fixed per configuration, unit 2-norm. Identical bytes are reused for every M, checked by SHA-256 at each M.
- 10 Gaussian X ~ N(0, I_{3N}): seeds 1001–1010 (`numpy.random.default_rng`), translation component removed.
- Spectral:
  - eigenvectors of sym(Γ_ref) outside the translation space (the three translation eigenvalues, |λ| ≤ 1.1e-15, are
    identified by their overlap with the translations);
  - the 3 slowest (smallest positive eigenvalues) and the fastest.
  - These are our own choices; the Landau paper does not specify its spectral probes.
- 3 translations 1_N ⊗ e_a/√N: only absolute and operator-normalised residuals are reported.
- Synthetic Maxwellian velocity vectors are not used: with T₀ = m = 1 and normalisation they have the same distribution
  as the Gaussian probes.

**Fig. 1(d):**
- Strict cutoffs; Gaussian probes.
- One curve per family and N: colour and marker give the family, line style gives N. Each curve is the maximum over the
  10 Gaussian probes and, for N = 128/256, over the 3 seeds.
- The y-axis is "maximum over tested probes/configurations", not a maximum over all X.
- With the production cutoffs, the complete error does not depend on M (Section 5.3). Those curves are shown in Fig. S2,
  not in Fig. 1.

### 5.2 Results: strict cutoffs (Fig. 1(d))

- The complete error falls from 1e-9 to about 1e-14 for every family and N:
  - Gaussian: 1.0e-9 (N = 128, M = 20) → 1.0e-14 (M = 64);
  - 1.6e-9 (N = 256, M = 24) → 9.5e-15–9.9e-15 (M = 80);
  - 1.6–1.7e-9 (N = 512, M = 30) → 1.4e-14 (M = 96).
- **Least-squares rates** on the points ≥ 1e-13, per family and N:

  | probe class | rate | R² |
  |---|---|---|
  | Gaussian | 10.10–10.32 | ≥ 0.9995 |
  | slow spectral | 9.99–10.31 | ≥ 0.999 |
  | fast spectral | 10.04–10.49 | ≥ 0.997 |

  These are measured rates for p = 9, not a proven order.
- The three families lie on top of each other: at equal N and M they differ by ≤ 12% (points ≥ 1e-13; Table "(d) per family"). The
  curves shift with N only because the box grows: L = 5.55, 6.99, 8.81, so the same M means a coarser grid h = L/M.
- The last points (1–2e-14) sit at the reference/round-off level and are excluded from the fits.

### 5.3 Results: production cutoffs (Fig. S2, Table "(d) N = 512")

- At the production parameters, the complete error is the same for every admissible M. It equals the fixed-cutoff value
  ‖(Γ_S^{r_c} + Γ_L^{k_c} − Γ_ref)X‖/‖Γ_ref X‖ of the r_c/k_c truncation (fitted slope ≈ 0).
  - The mesh contribution is visible only on the smallest grid of each size: Gaussian +3% at N = 512, M = 28; the fast
    probe up to M = 32.
  - With p = 9, the accuracy at the production cutoffs is set by r_c and k_c, not by M.
- **Range over all 21 configurations and all M:**
  - Gaussian: **2.0–2.9e-8**;
  - slow spectral: **4.9–8.1e-8**;
  - fast spectral: **0.84–2.0e-8**.
- **N = 512 at the production grid M = 40:**

  | family | Gaussian (10) | slow spectral (max of 3) | fast spectral | dense E_op |
  |---|---|---|---|---|
  | uniform | 2.59–2.68e-8 | 5.91e-8 | 1.77e-8 | 3.33e-8 |
  | moderate | 2.27–2.37e-8 | 5.96e-8 | 1.40e-8 | 3.02e-8 |
  | strong | 2.01–2.14e-8 | 8.05e-8 | 8.60e-9 | 3.03e-8 |

- For `strong_N512_s1`, the dense E_op at M = 40 is 3.0344442e-8, matching the joint optimisation to 1.1e-9 relative.
- All values are 7–10× (Gaussian) and 2.5–4.1× (slow spectral) below the 2e-7 budget.

### 5.4 Which X is hardest?

**Relative error:** the slow spectral probes are hardest.
- At N = 512 strong, M = 40: 8.05e-8 vs 2.14e-8 for the Gaussian probes, about 3.8×.
- Their reference action is the smallest: ‖Γ_ref u‖ = λ_min = 2.30, vs about 11.7 for Gaussian probes and
  ‖Γ_ref‖ = 17.55.
- The operator-normalised error is not larger: 1.07e-8 (slow) vs 1.42e-8 (Gaussian).
- The more clustered the configuration, the smaller λ_min: at N = 256 it is 4.37–4.47 (uniform), 4.08–4.26 (moderate)
  and 3.46–3.50 (strong). So the slow-mode relative error grows with clustering: 5.8e-8, 6.1e-8 and 8.0e-8 at N = 256.

**Strict cutoffs:** all probe classes converge at the same rate. The slow modes stay within a factor 1.4 of the
Gaussian probes.

### 5.5 Translation null space and structural checks

**Translation residual ‖Γ_h T_a‖/‖Γ_ref‖₂** (Fig. S3):
- pair-difference: ≤ 1.5e-16; exactly 0 at N = 256, where 1/√N = 2⁻⁴ is exact;
- cached D − H: ≤ 2.9e-16;
- Γ_ref itself: 3.2–4.9e-16.

**Other checks**, over all 399 valid cases:
- The dense Γ_h agrees with the matrix-free action to ≤ 3.8e-15.
- Symmetry defect ≤ 1.4e-17.
- Cached vs pair-difference ≤ 2.2e-15.
- No negative eigenvalue on Range Π.
- λ_min(Γ_h) deviates from λ_min(Γ_ref) by ≤ 7.8e-8 (production) and ≤ 5.7e-11 (strict), relative.

**Spectral probes** (`strong_N512_s1`): eigen-residuals ≤ 7.7e-15; relative gaps to neighbouring eigenvalues 0.011,
0.011 and 0.017 (slow) and 0.004 (fast).

### 5.6 Supplementary: assignment order p (Fig. S4, `run_exp1.py action_p`)

- **Setup:** N = 512 strongly clustered, strict cutoffs, p = 4, 6, 8, 9; every other parameter identical; only M varies.
- **Complete-error rates** (Gaussian / slow; least squares, R² ≥ 0.998):

  | p | rate (Gaussian / slow) |
  |---|---|
  | 4 | 4.19 / 4.12 |
  | 6 | 6.46 / 6.37 |
  | 8 | 8.81 / 8.73 |
  | 9 | 10.32 / 10.15 |

- These are measured rates: about p for even p and about p + 1.3 for p = 9.

## 6. What the data support

**Directly measured:**
1. The split identity holds to ≤ 3.0e-16 (Frobenius) and ≤ 1.9e-15 (per pair), for ξ ∈ [0.5, 1.5], three families,
   down to r = 1e-6.
2. E_S decays as e^{−c s²} with c = 0.981–0.988 down to a 3.5–4.1e-15 reference/round-off floor. The certified bound is
   1.4–1.9× the observed error.
3. With strict cutoffs, the matrix-free PPPM action converges to the independent periodic reference down to about
   1e-14. The fitted rate is about 10 for p = 9, independent of the configuration family, N (128–512) and the probe
   class.
4. At the production parameters, the action error is 2.0–2.9e-8 (Gaussian), 4.9–8.1e-8 (slow spectral) and
   0.84–2.0e-8 (fast spectral) for every admissible M. This is the value set by the fixed r_c/k_c, below the 2e-7
   budget.

**Interpretation, not proven here:**
- The cause of c < 1.
- The cause of the odd-p rate p + 1.3.
- Behaviour for N > 512.
