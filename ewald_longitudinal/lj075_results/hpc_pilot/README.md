# LJ law A HPC short pilot

**Status: not run on HPC.** This session has no Slurm or ssh access, so the five jobs were not submitted. The results
here are from a **local emulation**: the same job scripts run under bash on the development VM. They are not
cluster results.

## What was run

Four cases, each to t = 1 from the shared canonical state `init_state_eqA_lgv_s305_t50.npz`:

| case | O-step operator | dt |
|---|---|---|
| dense_dt0.005 | full periodic lattice-sum Γ (k = 0 kept), dense matrix functions (`toy_run.py --method reference`) | 0.005 |
| fast_dt0.005 | PPPM Γ_h (mesh M 24, k = 0 kept), Lanczos 14/5 (`--method pppm_lanczos`) | 0.005 |
| dense_dt0.01 | as dense above | 0.01 |
| fast_dt0.01 | as fast above | 0.01 |

The model is `lj_rho0.75_kT1.0_A_prod` (LJ, law A, N 256, ρ* 0.75, kT 1).

All cases use the same conservative force and the same runner. At each dt, fast and dense share every
standard-normal input (same seed). The two step sizes are not coupled: they use different seeds, and no pathwise
cross-dt comparison is made.

Driver: `../../lj075_hpc_pilot.py`. Slurm scripts: `../../hpc/lj075_pilot_case.sbatch` and
`../../hpc/lj075_pilot_analyze.sbatch`. Submission: `../../hpc/submit.sh lj075-pilot`. Local emulation:
`../../hpc/lj075_pilot_local.sh`.

## Running it on the cluster

```bash
cd ass1/ewald_longitudinal
cp hpc/cluster.env.example hpc/cluster.env      # fill in every FILL_ME (account, partition, paths, PY_SETUP)
bash hpc/submit.sh lj075-pilot --dry-run        # prints the 4 case sbatch commands and the analysis job (afterany)
bash hpc/submit.sh lj075-pilot                  # submits them; prints job ids and the pilot root
squeue --me
sacct -j <ids> --format=JobID,JobName,State,ExitCode,Elapsed,TotalCPU,MaxRSS,ReqMem,NodeList
```

Then copy `$RUN_ROOT/lj075_pilot/<tag>/report/` here (for example as `hpc_<jobid>/`) and commit it. Add no replicas
on the basis of this pilot.
