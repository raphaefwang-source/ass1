# Final report (kappa = 1)

1. Balanced Ewald choice x = y = s: YES for the two Ewald tails.  Over s in [2.5, 5], measured eps_S/exp(-s^2) = 0.34-0.79 and eps_F/exp(-s^2) = 0.18-0.44 (both configs): both tails follow exp(-s^2) with O(1) prefactors below 1, and the two are within a factor ~2-3 of each other.
2. s0 = sqrt(log(1/tol)) for the Ewald part alone: (eps_S + eps_F)/tol at s0 = 0.64-1.1.  It is marginal, not systematically optimistic by a large factor: meeting eps_S + eps_F <= tol/2 needed s = 1-1.1 x s0 (explicit search).  sqrt(log(2/tol)) is about 1.02-1.05 s0 and matches that margin.  Predictor A (C = 1) gives s ~ 1.04-1.07 s0 and meets the tails with margin.  Predictor B's Fourier mapping (coherent, proportional to V) overpredicts eps_F by 76-5.3e+02x, so s_B over-resolves; the real-space mapping E_S/||K||_L1 is within 1-2x of the measured value.
3. Dominant error once the tails are small: {'eps_S': 4, 'eps_transfer': 20} (main runs, eta_N = 0.7, p = 4).  The mesh error is almost entirely the position-dependent transfer term: eps_transfer/eps_alias = 22-2.2e+05.  The heuristic q^p overestimates the measured mesh error by 37-1.5e+05x, and at fixed eta the mesh error still falls as the mesh refines with s (it depends on xi h, not only on eta).  It decays algebraically, not like exp(-s^2), so it sets the achievable tolerance.
4. Raw Gamma_h PSD: classes over all 226 runs = {'A': 222, 'B': 4} (A certified, B observed only, C indefinite).  No run was indefinite; the smallest lambda_h/lambda_* was 0.9932.  Uncertified runs: B p=2 eta=0.6 err_abs/lambda_*=1.18, B p=2 eta=0.7 err_abs/lambda_*=1.49, B p=2 eta=0.8 err_abs/lambda_*=1.56, B p=2 eta=0.8 err_abs/lambda_*=1.13.  Certification holds whenever err_2 < lambda_*/||Gamma||_2 (= A: 3.0e-02, B: 4.4e-03).
5. The spectral-gap certificate is very conservative: the actual shift lambda_* - lambda_h is only 1.2e-02 (median), max 0.25, of ||Gamma_h - Gamma||_2.  The Weyl bound lambda_h >= lambda_* - ||dGamma||_2 held in 226/226 runs.  The error budget sum/actual = 1-2.6, so it is conservative (guaranteed >= 1 by the triangle inequality).
6. Stabilisation: NOT needed in the tested regime (tol 1e-3 to 1e-9, p 2-8, eta 0.3-0.8).  The negative eigenvalue of Khat_L never produced a negative eigenvalue of Gamma_h.

Measured cheapest settings meeting the full tolerance: A tol=1e-03: eta=0.8, p=3, M=14; A tol=1e-05: eta=0.8, p=6, M=17; A tol=1e-07: eta=0.5, p=6, M=32; A tol=1e-09: eta=0.45, p=7, M=40; B tol=1e-03: eta=0.8, p=4, M=23; B tol=1e-05: eta=0.7, p=5, M=32; B tol=1e-07: eta=0.5, p=6, M=54; B tol=1e-09: eta=0.45, p=8, M=66.
